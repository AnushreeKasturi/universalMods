What you get

A thin shell, with everything else built as a mod you can change.

🖥️ Live terminals

Every agent runs its real CLI. Click its tile and its terminal fills the pane: watch it work, type into it, or queue messages. A permanent master orchestrator is always there.

🐝 A shared hive

Every agent gets hive tools: a kanban, a plan board, messages to other agents, spawning teammates, and ask_user when stuck.

🗺️ Live roadmap

A PM agent drafts a roadmap from your brief and renders it as a Mermaid flowchart. Progress moves as tagged kanban tasks get done.

🛡️ No limits, with guards

Agents run unrestricted by default. A mod can still deny a dangerous call before it runs, on either platform.

🧱 Your layout

Put any view in any pane: grid, timeline, kanban, roadmap or your own. Save named layouts and share them with ?layout=.

✨ Mods from a sentence

Describe a mod in plain English. A Mod Builder agent writes it, checks it loads, and it hot-reloads straight into your floor.

A mod is a folder

Drop a folder into mods/ with a mod.json, then add a server half to hook events, a client half to add views, or both.

  • Same hook rules as Claude Code. Call next() to pass an event on, return a value to answer it, or call next({...e}) to rewrite it.
  • Give agents new tools. $.tool.register adds a hive tool on both platforms.
  • Patch platform config. config.build lets a mod tweak each agent's Codex TOML or Claude settings.
  • Views in React. registerView plus hooks for the live floor state.
// mods/budget/server.ts: hold agents that overspend
export const register = (on, options) => {
  on('agent.event', (e) => e.event.kind === 'usage',
    ($, e, next) => {
      if (e.agent.usage.costUsd > 0.5) {
        $.agent.hold(e.agent.id, true);
        $.ui.toast(`${e.agent.name} hit the budget`);
      }
      return next();
    });

  // guard: works on Codex and Claude alike
  on('tool.call', ($, e, next) =>
    /rm -rf \//.test(e.input?.command ?? '')
      ? { decision: 'deny', reason: 'nope' }
      : next());
};

One floor, one platform

Codex and Claude Code configure the same things very differently, so each floor runs one platform and has a config adapter for it. Your global ~/.codex and ~/.claude setup is never modified.

🚧 Multiple agent providers support coming soon. universalMods currently targets Codex and Claude Code only. Support for more agent platforms is coming. Each platform is a provider under src/providers/, so contributions are welcome.

Quick start

You need Node 20 or later, plus Codex or Claude Code installed and logged in.

Clone and install
git clone https://github.com/samridh3215/universalMods.git
cd universalMods && npm install
Start a floor
npm run dev -- --provider codex     # or: --provider claude
Open the printed URL (it includes ?token=…). Add &layout=showcase for the view in the screenshots, spawn agents, and build mods from the 🧩 menu.
Optional: give your agent the skill
/plugin install universalmods --marketplace samridh3215/universalMods

⚠️ Agents run with no permission limits and can do anything your user account can. The server binds to 127.0.0.1 and requires the per-run token.
